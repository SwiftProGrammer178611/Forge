# Forge
This is a habit tracker and you cna save your habits as well in local storage!
Link to try it out: https://forge-lime-psi.vercel.app/

## How to Work it:
- add a name to the habit
- add the duration
- select the frequency
- click add habit
- you can check the box, and you can delete the habit

That's it!
MOSST OF ALL, DON'T FORGET TO: HAVE FUN!!!

## Tech Stack:
HTML,CSS,Javscript

## Goal of this project:
TO create an all in one productivity tool that encompasses all that I need when I am studying/working so I don't have to use multiple different tools

## Things I learned:
Extensive DOM Manipulation, in complex ways, and also Animations, like for the pomodoro timer. I also leanred how to create draggablle 'windows' for the kanban. Notes was simple. I also learned how to use and read thigns from localstorage for persistent data for kanban board, and habits. Later I plan to do this for pomodoor ssessions tracked and also for notes as well.
