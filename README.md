# Forge
This is a habit tracker and you cna save your habits as well in local storage!
Link to try it out: https://forge-lime-psi.vercel.app/

## How to Work it:
- add a name to the habit
- add the duration
- select the frequency
- click add habit
- you can check the box, and you can delete the habit

That's it!
